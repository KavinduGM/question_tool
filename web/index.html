1. Clone a new voice

For best fidelity, upload 3–5 minutes of the target speaker reading varied sentences (mix of statements and questions, neutral mood, no background music/other voices). Up to 5 minutes is kept; the server splits it into ~30 s segments and XTTS averages the speaker embedding across all of them — that averaging is the main lever for cloning accuracy.

3. Generate audio

ZIP batch: put a line containing only <<<QUESTION>>> between each full question (stem, choices, answer, explanations). Each block becomes question_001, question_002, … in the chosen format inside one zip.

Output format

4. Batch generate (DOCX queue)

Add one or more Word documents. Each document gets its own subfolder under the selected output folder, then audio is generated for every Voice N block inside it. Format A (Voice 1, Voice 2 … flat list) saves files directly inside the doc subfolder; Format B (with Animation N headers) saves into per-group subfolders. Format A only: a Voice Name: P3: What Are Virulence Factors line before a Voice N block becomes the saved filename (illegal characters like : are replaced with _). Uses the same voice, speed, and output format (WAV / MP3) selected in section 3.

Add as many as you want. Each row's subfolder name is editable until generation starts.

5. Quiz question generator (DOCX queue)

Add one or more quiz documents. Each block must start with Question N, followed by the question body, four a./b./c./d. answer lines, a Correct Answer: line, an Explanation: paragraph (correct option), and three Option X is incorrect because … paragraphs. For each question the system synthesises four voices — Voice 1 (number + question), Voice 2 (answers + correct line), Voice 3 (correct explanation), Voice 4 (incorrect explanations) — then merges them with a configurable pause and saves a single Question N file per question. Uses the same voice and output format (WAV / MP3) selected in section 3.

Add as many as you want. Each row's subfolder name is editable until generation starts.
